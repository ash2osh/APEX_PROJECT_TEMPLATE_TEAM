# Alias-keyed application context

Store durable knowledge below `app_context/<alias>/` only. Suggested files are
`purpose.md`, `data-dependencies.md`, `subscriptions.md`, `known-issues.md`,
and `recovery.md`. Keep connection names, passwords, local defaults, logs, and
sync state out of this directory. Context is advisory; target contracts and
verified SQLcl identity remain authoritative.
